DocuAll
DocuAll, dijital belgelerin saklanması ve kullanıcıların yetkilerine göre belgelere erişebilmesi için hazırlanmış basit bir dijital arşiv projesidir.

Özellikler
  Kullanıcı giriş ekranı
  Dijital arşiv ana sayfası
  Belgeleri listeleme
  Belge yükleme
  Kullanıcı rolüne göre belge erişim durumu
  Yetkili ve yetkisiz erişim için uyarı mesajları
 
Kullanılan Teknolojiler
  HTML
  CSS
  JavaScript
  Font Awesome
  Google Fonts
  
 Çalıştırma
    Projeyi indirdikten sonra anasayfa.html dosyasını tarayıcıda açarak çalıştırabilirsiniz.
